How it works

Photos go in, a scaled drawing and a confidence verdict come out. Stage 1 needs a GPU; stages 2 to 4 run on any CPU.

Stage 1 · Photogrammetry (GPU)

Structure-from-Motion finds the camera positions; Multi-View Stereo builds a dense surface. The dense step is the one that needs a CUDA GPU. The mesh gets its real-world size from printed markers: two markers a known calliper distance apart fix millimetres-per-unit. Manual today The planned wrapper lives in gpu/.

Stage 2 · Cleanup (clean_mesh.py)

A raw mesh contains the sherd, the turntable, the backdrop and floating noise as separate connected pieces. The script keeps the piece with the most triangles. A turntable is a large area built from few triangles; the photographed sherd is a small area built from very many. On the sample mesh this took 710 components down to 1.

It also reports how much it kept and whether what remains is compact, so a human can spot a bad cleanup.

Stage 3 · Profile (extract_profile.py)

Why the axis is everything

A wheel-thrown pot is a surface of revolution: every horizontal slice is a circle around one vertical axis. If you know the axis, the profile is simply "radius at each height". If the axis is tilted by a few degrees, the radius is wrong by an amount that grows with distance from where you anchored it. So finding the axis is the whole problem for fragments.

Complete vessels: pca

  1. Seed the axis with the mesh's longest direction (PCA).
  2. Slice perpendicular to it, fit a circle to each slice with outlier rejection (so a handle doesn't drag the centre), and refit the axis through all the circle centres. Repeat.

Rim sherds: rim_arc

This mirrors the archaeologist's rim chart. The rim and clean breaks are horizontal circular arcs on the mesh border.

  1. Collect the border vertices (edges used by only one triangle).
  2. Take the top and bottom height bands and fit a plane and circle to each.
  3. Accept an arc only if it passes three gates: a clean circle (residual below 0.05), a long enough arc (at least 70°), and nearly planar (planarity below 0.12, which rejects a flared mouth).
  4. Use the best arc's plane normal as the axis.
  5. If no arc passes, fall back and flag the sherd rather than guess.

Cutting the profile

Every vertex is expressed as height along the axis and distance from it. The height range is split into bands (300 by default). In each band the median radius is the wall. Median rather than mean or maximum, because a handle covers only a minority of the circumference and the median ignores it.

Wall thickness

For a sherd that captured both surfaces, each band's radii form two clusters. A one-dimensional Otsu threshold splits them into an inner and outer wall and thickness is the gap. A mesh with only an outer surface is a single cluster and correctly reports no thickness.

Stage 4 · Publish (publish_svg.py)

Plain SVG editing, no GUI: adds a metric scale bar, a caption and the 0.3 mm line weight. The profile geometry is not touched; the test suite checks that polylines and scale are identical before and after.

What the numbers rest on

An error-vs-truth oracle crops wedges of increasing width from a complete vessel with a known axis, runs the pipeline on each, and measures axis angle and radial error directly, with no alignment heuristic. A second test builds a vessel with an exactly known profile and reads the published SVG back to compare against it. See sample output.
