Proof of concept

Photograph a sherd.
Get a measured drawing.

archaemetry is a low-cost, field-portable pipeline that turns photographs of archaeological pottery into a scaled 3D mesh and a publication-style profile drawing, with a built-in check that says when the result can be trusted.
