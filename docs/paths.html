CPU & GPU paths

Both paths run the same four stages. They differ in where photogrammetry (Stage 1) runs. Stages 2 to 4, where the drawing is made, are CPU-only on both.

Tested verified by us on known test data   Built, not validated code exists   Prototype experimental   Manual done by hand in a GUI   Planned not built yet   Not tested not tried

GPU path

Photogrammetry on a CUDA GPU: fast, the likely production route. Local card is an RTX 3050 (4 GB), which is slow on 150 images, so rented GPUs are an option.

CPU path

No GPU needed anywhere, so it runs on any laptop or server. Photogrammetry is much slower. Also covers starting from an existing mesh, such as a museum scan.
