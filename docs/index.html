archaemetry

A low-cost, field-portable photogrammetry pipeline that turns photos of pottery sherds into metric 3D meshes and publication-style profile drawings.

GitHub repository Project handoff Validation write-up

What it does

For each sherd: a scaled 3D mesh, a cross-section profile drawing (with wall thickness where both surfaces are captured), and for decorated ware a flattened rollout. Proof of concept on a consumer camera, a cardboard light tent and mostly free software, with an upgrade path once funded.

Pipeline

1 · PhotogrammetryImages to scaled mesh. GPU stage. ArUco markers + calliper distances set the metric scale. Not yet scripted.
2 · CleanupKeeps the largest component by face count, dropping turntable and noise. CPU, scripted.
3 · ProfileSymmetry axis fit (pca or rim_arc), inner/outer wall split, thickness. CPU, scripted.
4 · PublishScale bar, caption and 0.3 mm line weight as portable SVG. CPU, scripted.

Every run ends with a GO / REVIEW verdict. A fragment whose axis can't be fixed from a clean rim arc is flagged for manual review instead of being silently drawn.

Run it

cd scripts
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run.py --config config/sherd.example.yaml --input mesh.obj --outdir out/
python tools/synthetic_validation.py out_check/   # accuracy check, ~30 s, no downloads

Linux needs libegl1 for Open3D. The whole profile lane is CPU-only.
